# detect_pretrained.py, vendor/syncnet_python/) -- the actually-deployed detector

# which is specific to the old/unused mediapipe-based preprocess.py path.

# repeated here). torch/scipy/numpy/tqdm are already satisfied by the root

#   venv312\Scripts\pip install -r Speech\requirements-av.txt -r Speech\requirements-syncnet.txt

# vendor/syncnet_python/run_pipeline.py and SyncNetInstance.evaluate() shell out to
# it directly.

# don't "fix" it by bumping click, or scenedetect's own import breaks instead.
